# 交接：编辑卡片外观 + 空文档标题占位（2026-11-12）

本轮改动**均未提交**，都在 `main` 的工作区里。`gofmt -l .`、`go vet ./...`、`go test ./...` 全部通过。
（`.ryugi/` 是工具产物，不属于本轮改动，提交时别带上。）

## 做完的

### 1. 编辑卡片：亚克力半透明（参照 beacon）
- 新文件 `internal/nativeui/appearance.go`：不透明度、背景材料、卡片宽度三项设置，存到 `appearance.json`。
- 卡片底色 = 主题卡片色 × 不透明度（默认 0.30，下限 0.30，与 beacon 相同）；颜色本身跟着主题走，不开放调色。
- 背景材料四档：无 / 弱 / 中 / 强，对应 `mygo.Vibrancy` 的 None / Sidebar / Popover / Acrylic。窗口按存下的档位创建（`run.go`）。
- 设置 → 外观里新增「卡片不透明度」滑杆和「背景材料」分段控件。
- 浅色主题里编辑器内部的 `panel`（表格、引用、图片的底）改成半透明（`mdedit/layout.go`），否则会在亚克力上抠出一块不透明的底。

### 2. 卡片左边缘拖动改宽度
- `cardWidthPref` 存的是卡片左边缘**离窗口左边缘**的距离；卡片和面板之间的缝由 `canvasLeft()` 现算。
- 往左拖：最多贴到面板右边缘（`cardMinLeft`），盖不住面板；往右拖：卡片至少留 320px（`cardMaxLeft`）。
- 双击手柄恢复成跟随面板。

### 3. 修了两个 bug
- 空文档里按 Backspace / Delete 会把唯一的空行删掉，「开始写作…」跟着消失 → 现在这一行一直保留。空文档里多敲的回车，Backspace 一次收回一行。
- 正文左右留白 40px → 24px（`mdedit/layout.go` 的 `defaultPadX`）。

### 4. 空文档的标题占位（像 Notion，但标题存在文件里）
- 新文档第一行显示一级标题字号的灰字「标题」；打字后存成 `# 周报`。
- 标题写完回车，下面那行显示「开始写作…」。
- 空标题上按回车 = 不要标题，这一行变成正文；接着按 Backspace 又还给标题。
- 在空标题里敲 `- `、`> `、`## `、```` ``` ````、图片等，照常起对应的块，不会被套上 `# `。
- 标题前敲空格不会写进文件。
- 中文输入法上屏（包括带替换范围的上屏）同样写成标题。
- 第一次保存时，保存框默认文件名取标题（`周报.md`）；文件系统不收的字符换成空格，最长 80 字。「要保存更改吗？」那条路径也一样。
- 代码文件（`.go`、`.json` 等）没有标题占位。
- 开关：`mdedit.Options.TitlePlaceholder`，app 在 `editorOptions()` 里设为「标题」。

## 没做 / 待定
- **正文列限宽 820px 没动。** 宽卡片里正文两边各剩一百多像素，那是限宽留出的余量，不是留白。要不要放宽还没定。
- **标题占位只在单元测试里验证过，没在真机上看过。** 需要真机过一遍：中文输入法、亚克力背景下灰字够不够清楚、深色主题。
- 卡片拖动同样只有测试和数值探针，真机拖动的手感没确认。
- 打开一个已有的空 `.md` 文件，也会显示标题占位（与新建一致）。如果不想这样，需要区分「新建」和「打开」。
