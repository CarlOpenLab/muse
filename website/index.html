03 — 图与公式

同一支笔，画出一切

流程图、时序图、饼图、甘特图，由 Mermaid 子集原生绘制； 行内与块级公式由 go-latex 排版。图不是贴进来的图片， 而是和文字同一套渲染管线画出来的。

04 — 键盘

双手的编排

⌘B 加粗，⌘K 链接，⌘0–6 换层级，Tab 缩进列表，Shift+Enter 硬换行。 双手不离键盘时，Muse 接得住每一个意图。

原生的力量

—— 语法由 Muse 替你写好，双手无需离开键盘。

  • ⌘B 加粗 原生的力量 ← **原生的力量**
  • ⌘K 链接 文字 ← [文字](url)
  • ⌘2 二级标题 H2 ← ## 原生的力量
  • ⇥ 缩进列表 嵌套一层 ← Tab 缩进
05 — 内核

纯净的原生

整个应用是一个 Go 二进制：窗口、图标栏、上下文面板、编辑器、AI、图表， 全部由 MyGo 直接绘制。没有浏览器内核，就没有浏览器的重量。
