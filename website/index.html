01 — 缪斯 AGENT

会读工作区的写作伙伴

13 个文档工具：列出、读取、搜索、大纲、目录树、统计、重命名、回收站删除…… 每一步都落在对话里——看得见，批得了。

AI 助手
让 Agent 总结、改写或编辑这篇文档…
deepseek 清空

工具审批卡

每次改文档前，Agent 把要做什么递到你面前：同意这一次、本会话都允许，或者拒绝。拒绝的原因会回到对话里，Agent 自己改道。

权限三档

每次询问、完全访问、只读——就在输入框旁边切换。会话内生效，重启恢复默认。

能力按组开关

浏览搜索、编辑内容、管理文件三组工具在设置里独立开关；没开的组不会发给模型，也不会被执行。

过程全可见

思考可折叠回看，每次工具调用带状态与参数，左右分列——你的话靠右，Agent 的每一步靠左。

↑ 演示是真的：点「同意修改」，或把权限切到「只读」再重播。

02 — 原生

没有 WebView，每一帧由 Go 绘制

整个应用是一个 Go 二进制：MyGo 把界面画在 GPU 上（Metal / Direct3D 11 / OpenGL）， mdoc 负责把 Markdown 排成版式。点击段落，直接在排好版的文字里编辑——标记隐去，缪斯到来。
